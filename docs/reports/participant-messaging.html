Participant messaging build report

13 November 2026 · Local development branch · Bangkok time (UTC+7)

Three senders can use Tor, Outline Shadowsocks and direct access in the same simulation. Each enabled, online client polls at a fixed interval even when an earlier poll is in flight. The graph shows poll movements and results. Visible message lines measure 1.25 CSS pixels, with a 13-pixel pointer target. The chat filter counts received messages per contact.
