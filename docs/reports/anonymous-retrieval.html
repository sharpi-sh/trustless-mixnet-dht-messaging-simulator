Anonymous retrieval

The reader sends manifest and fragment requests through three mix layers. The service receives a sealed request and uses the enclosed reply blocks to return encrypted data. Both Alice and Bob use this protocol. In the seeded example the two independently sampled routes share one relay.

retrieval-4-q0 receiver-1 → tor-receiver-1 → provider-east → mix-10 → mix-2 → mix-3 → provider-west → storage-3
retrieval-4-r0 storage-3 → provider-west → mix-10 → mix-8 → mix-6 → provider-east → tor-receiver-1 → receiver-1

Protocol boundaries

This is a local application of the Nym whitepaper’s anonymous reply design using the simulator’s Sphinx format. The lab assumes per-run service keys and local reply-block expiry. It omits Nym’s network-wide key rotation, live gateway acknowledgements and interoperability with deployed Nym nodes. Timing, replica choices and repeated lookups still provide correlation signals.
