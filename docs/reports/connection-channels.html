Protocol scope

Tor and Outline Shadowsocks simulate address visibility. All addresses are synthetic. Direct access uses the device address on remote links. Message deposit uses Loopix. Device polling and vault reads use the selected connection. The simulator models neither public network behaviour nor a measured anonymity guarantee.
